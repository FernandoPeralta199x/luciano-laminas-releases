# Luciano Lâminas — Releases

Canal público oficial de atualização do aplicativo **Luciano Lâminas Comercial e Móveis**.

Este repositório contém somente artefatos publicados pelo pipeline de release:

- instalador Windows;
- pacote incremental de atualização;
- `update-manifest.json`;
- `SHA256SUMS.txt`;
- notas de versão.

O código-fonte, dados comerciais, credenciais, logs e certificados não são publicados aqui.

> Não envie arquivos manualmente para a branch `main`. As versões devem ser publicadas pelo GitHub Actions do repositório privado de código-fonte.
